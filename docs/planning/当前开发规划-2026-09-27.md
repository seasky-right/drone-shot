## 目标和边界

平台提供外部 Agent 的输入/输出契约、运行环境、能力检查、任务执行、记录和比较；内置 Agent 是示例或 baseline，不是平台产品的算法核心。Backend 是仿真器适配层，World/Scene Resource 是场景资产及其坐标、几何和语义元数据，Scenario/Task Instance 是在该资源上按规则确定的一局初态、目标和约束。Task 定义这一局做什么及何时结束；Evaluator 计算逐局指标；Benchmark 规定案例集、重复与汇总政策。Agent 只能获得声明为公开的任务和观察，不能获得隐藏目标真值。MCP 可以以后作为 LLM Agent 接入适配器，不是平台协议或所有 Agent 的前提。

目标是让符合公开候选协议、且能力相容的新 Scenario/Generator、Task、Evaluator 和 Benchmark Pack 经配置接入已有运行链。新运行语义、权限或资源操作超出现有契约时仍需提出可复现的缺口，版本化修改 Contract/Core；不承诺任意新场景即插即用，也不把 UE4 固定场景作为通用机制的前提。
