# 空间 Pack 阶段验收（2026-09-28）

本记录只验收 D0-D4 的无仿真技术样例；v0.2 AirSim 在真实 UE4 固定场景的单机证据另见[真实验证](AirSim-v0.2-UE4真实验证-2026-09-28.md)，不能与本记录互相替代。F07/F08/F10/F11 或 Plugin Contract C6 均未冻结。实现和实验由并行 Sol subagent 完成；Astra 对照[当前开发规划](../planning/当前开发规划-2026-09-27.md)审查代码、差异和证据。

## 交付范围

| 范围 | 实现与边界 |
| --- | --- |
| Core 编排 | 固定 Scenario 或 Generator+seed、Evaluator、逐案例 Benchmark 和 Result Processor 接线。校验生成场景 ID、seed 与覆盖规则；案例预检发生在执行前。异常在 episode/benchmark 事件记录 `component_error`，记录保持 `INCOMPLETE` 且不可当作完成结果读取。 |
| Spatial World Pack | 独立 wheel，版本化 `local_ned` 世界 JSON、公开边界/障碍、候选出生/目标点、确定性生成和 Mock Backend。ReachPoint 公开目标；SearchTarget 的精确目标 ID/位置留在 `truth`，公共观察只有搜索区域、有偏差检测与 Agent 报告回显。 |
| 可行性与 reset | 枚举合法点对，校验边界、障碍、最小间距及直线路径；无候选立即失败，无随机重试。seed 决定实例及 SearchTarget 的检测器模式。Mock reset 恢复位置、目标、检测状态、报告和序号；无真实传感器或仿真缓存。 |
| Spatial Task Pack | 独立 wheel，ReachPoint 的完成与米制距离/路径指标；实验版 SearchTarget 的 REPORT 目标 ID 与位置匹配、漏检/误报、定位误差、传感器不可用与无检测分离。报告重复计为额外误报；规则与单位见 Pack README。 |
| Benchmark | 两套版本化三种子案例，ReachPoint direct/staged 和 SearchTarget confident/offset 各用同一实例比较。完成的失败计入分母；episode 异常导致 Benchmark 中止，不产出汇总。 |

World Pack 在 `examples/spatial_world_pack/`，Task Pack 在 `examples/spatial_task_pack/`；各有 manifest、wheel 配置、示例和测试。Core 不导入这两个 Pack 或 AirSim RPC。

## 未完成关卡

- 这两个 Pack 的后端是 Mock；其点位、检测和 reset 证明只对打包的 JSON 世界成立。D5 已另行实测真实 UE4 固定场景的 v0.2 单机流程，但未接入本空间生成器和 SearchTarget；能力声明等未闭合项见[真实验证](AirSim-v0.2-UE4真实验证-2026-09-28.md)。
- SearchTarget 检测是 Mock 公共状态，不是 RGB/Depth 感知算法或真实目标真值采集。正式容差、安全规则、感知来源、重复和排名政策仍需 F08/F10/F11 确认；当前只报实验结果。
- 完成结果的失败计入分母；插件异常使 Benchmark 中止并留下不可重读的 `INCOMPLETE`，尚无“异常也占案例分母”的正式政策。
- C6 的受影响方确认未发生；v0.2 仍是候选协议。仓库外重新构建与安装证明 Pack 边界和公开接线，Pack 源码仍来自本仓库示例，尚不代表第三方作者反馈或其他引擎兼容。
