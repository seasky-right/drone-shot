## 尚未完成或验收的关卡

1. **P3 正式验收：**把已实测的场景/载具/传感器能力整理为 F07 正式矩阵；完成 F08 ReachPoint 规则、两套入口和安全收尾判据的跨 track 确认；明确航程碰撞不可观测时的验收政策，并按计划补第二个可切换 Agent 的真实场景证据。旧场景存在出生点碰撞、部分 RPC 布尔返回与实际状态不一致、landed 标记不稳定等兼容限制。
2. **P4 SearchTarget：**目前只有搜索路线 Agent；真实传感器输入、目标检测/定位、上报、独立真值评价以及 F10 的真值隔离尚未形成闭环。先核实旧场景是否提供可信目标与真值。
3. **P5 正式 Benchmark：**批量基础设施已就绪，但还需 F11 的 reset 初态、seed 控制范围、失败分母和比较规则；完成真实任务连续运行和至少三种 baseline 的同条件比较。当前 60 次 Mock 运行不能替代正式 Benchmark。
4. **远期阶段：**Headless/无人值守队列、GIS/遥感空间任务、场景随机化、训练接口、多机、Web/服务化及 Sim-to-Real 均属于[后续路线](../../综述.md)，没有本报告可据以标为已实现的验收证据。

本报告为 **2026-09-24 的工作区现状快照**。后续状态应随提交、正式决策及独立验证记录更新；真实仿真与无仿真结果继续分开记录。
